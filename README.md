# jahanvi-j.github.io

Personal portfolio of Jahanvi Jeswani. Plain HTML/CSS/JS, served by GitHub Pages.

- `index.html` — content (experience, projects, research, skills)
- `styles.css` — styling, light/dark themes
- `script.js` — theme toggle, scroll reveal, typed tagline
- `images/` — headshot, logo, resume PDF

Preview locally: `python3 -m http.server` and open http://localhost:8000.
